# drinksunboy.com theme

Shopify Online Store 2.0 theme for drinksunboy.com, built on [Shopify Dawn](https://github.com/Shopify/dawn) 16.0.0 (MIT, see LICENSE.md).

## Brand layer
- `assets/sunboy-brand.css.liquid`: Nobel web fonts and SUNBOY colour tokens.
- `assets/sunboy-*.svg`: logos converted from the Brand Kit Illustrator files (`-mono` versions follow the text colour).
- Colour schemes in `config/settings_data.json`: 1 white/brown, 2 teal, 3 yellow, 4 brown, 5 cream.

## Workflow
Shopify admin → Online Store → Themes → Add theme → Connect from GitHub → this repo, branch `main`. Edits made in the theme editor sync back as commits.
